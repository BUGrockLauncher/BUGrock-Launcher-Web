Feature 02

In-World Resource & Add-on Injector

No more com.mojang folder digging. Manage and toggle resource and behavior packs directly per world without opening confusing AppData folders.

Bedrock on Windows hides your save data deep inside sandbox packages. BUGrock reads your worlds and manages active packs directly from the UI with zero world corruption risk.

✓ One-click .mcpack & .mcaddon installation
✓ Individual world pack toggling
✓ Zero file manager navigation needed
