Core Features in BUGrock Launcher

A lightweight, modular Minecraft Bedrock Edition launcher for Windows 10 & 11 (x64) built around real instance isolation, dual package support, and zero bloat.

01 // VERSION MANAGER

GDK (.msixvc) & Legacy UWP (.appx) Support

Install and launch official Minecraft Bedrock Release, Preview, and Beta builds across modern GDK packages and classic UWP builds, or import local packages from disk.

  • Supports modern .msixvc (GDK) builds with launch shim support.
  • Registers legacy .appx builds directly via Windows AppX deployment services.
  • Built-in + Import .appx / .msixvc sideloading via file picker or drag-and-drop.
.msixvc (Modern GDK Package) GDK SUPPORT
.appx (Legacy UWP Package) APPX REGISTRATION
Local Package Sideloader DRAG & DROP / PICKER
02 // EDIT INSTANCES

Multi-Instance Data Isolation

Create, clone, rename, and manage separate profiles inside the Edit Instances tab so versions stay separated.

  • Each instance uses its own isolated com.mojang directory via folder junctions.
  • Prevents world corruption caused by opening older saves in newer game builds.
  • Backs up existing un-isolated directories before linking new instances.
Instance Junctions ISOLATED SAVES
03 // WORLD PROTECTION

Pre-Launch World Auto-Backup

Optional pre-launch backup routine that compresses your world folders into timestamped .zip archives before starting the game.

  • Creates timestamped world backups on disk with progress feedback before launch.
  • Includes a 1-click Local Data Directory shortcut in the sidebar to open your saves folder.
Auto-Backup Archive TIMESTAMPED .ZIP
04 // BUILT-IN CONTENT HUB

MCPEDL, CurseForge & Live Servers Browser

Browse and download community packs inside embedded WebView2 tabs without leaving the launcher, and join featured multiplayer servers with one click.

  • Dedicated categories for Add-ons & Mods, Texture Packs, Maps & Worlds, and Skins & Packs.
  • 1-click import for .mcpack, .mcaddon, .mcworld, .mctemplate, and .zip files.
  • Built-in Bedrock server browser (minecraftpocket-servers.com) with minecraft:// quick-join.
MCPEDL & CurseForge Tabs 1-CLICK IMPORT
minecraftpocket-servers.com MINECRAFT:// JOIN
05 // SKIN MANAGER & SETTINGS

3D Skin Preview & Low-Performance Mode

Preview your character skin in 3D from the sidebar and upload any custom .png skin with one click.

  • Low-Performance Mode toggle in Settings & Tools to disable UI animations on lower-end PCs.
  • Quick skin switching and preview cube inside the main launcher window.
06 // SYSTEM DIAGNOSTICS

Bundled BUGrock_Check Repair Utility

Diagnose package installation or Windows Store service issues automatically with the bundled BUGrock_Check helper tool.

  • Inspects core Windows deployment & gaming services: AppXSvc, ClipSvc, GamingServices, and wuauserv.
  • Performs 1-click startup repair if any required system service is stopped or disabled.

System Requirements & Quick Setup

Honest prerequisites and a quick checklist so packages install cleanly on the first run.

01 // OPERATING SYSTEM

Windows 10 / 11 (x64)

Windows 10 (Build 17763 or newer) or Windows 11 on 64-bit x64 architecture.

02 // UWP PACKAGES

Developer Mode ON

Required by Windows to sideload .appx packages cleanly.

Settings > System > For developers
03 // EXTRACTION PATH

Short Folder Path

Extract the ZIP to a short path to avoid Windows MAX_PATH errors.

C:\Games\BUGrock
