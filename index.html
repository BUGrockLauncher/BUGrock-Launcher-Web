Core Features in BUGrock Launcher

A lightweight, modular Minecraft Bedrock Edition launcher for Windows 10 & 11 (x64) built around real instance isolation, dual package support, and zero bloat.

01 // DUAL-ARCHITECTURE MANAGER

GDK (.msixvc) & Legacy UWP (.appx) Support

Install and launch official Minecraft Bedrock Release, Preview, and Beta builds across both modern GDK packages and classic UWP builds, or import local packages straight from disk.

  • Automatic decryption key resolution and native launch shim execution for modern .msixvc builds.
  • Direct package registration for legacy .appx builds via Windows AppX deployment services.
  • Built-in + Import .appx / .msixvc sideloading via file picker or drag-and-drop.
.msixvc (Modern GDK Package) KEY + LAUNCH SHIM
.appx (Legacy UWP Package) APPX REGISTRATION
Local Package Sideloader DRAG & DROP / PICKER
02 // EDIT INSTANCES

Multi-Instance Data Isolation

Create, clone, rename, and manage independent profiles inside the Edit Instances tab so versions never clash.

  • Each instance runs inside its own isolated com.mojang directory via safe junctions.
  • Prevents world corruption caused by opening older saves in newer game builds.
  • Automatic safety backup of un-isolated directories before creating instance links.
Instance Junctions ISOLATED SAVES
03 // WORLD PROTECTION

Pre-Launch World Auto-Backup

Optional background archive engine streams your world folders directly to disk as timestamped .zip backups before launching Minecraft.

  • Direct streaming ZIP engine with live progress feedback avoids UI freezes on large worlds.
  • Includes a 1-click Local Data Directory shortcut in the sidebar to jump right into your saves.
Auto-Backup Stream TIMESTAMPED .ZIP
04 // BUILT-IN CONTENT HUB

MCPEDL, CurseForge & Live Servers Browser

Browse and download community content inside integrated WebView2 tabs without leaving the launcher, and jump into featured multiplayer servers with one click.

  • Dedicated categories for Add-ons & Mods, Texture Packs, Maps & Worlds, and Skins & Packs.
  • 1-click import for .mcpack, .mcaddon, .mcworld, .mctemplate, and .zip archives.
  • Live Bedrock server list (minecraftpocket-servers.com) with minecraft:// quick-join and off-screen WebView2 memory suspension.
MCPEDL & CurseForge Tabs 1-CLICK IMPORT
minecraftpocket-servers.com QUICK-JOIN + IDLE SUSPEND
05 // SKIN MANAGER & UI ENGINE

3D Interactive Skin Viewer & Low-Performance Mode

Preview your character skin in real-time 3D right from the sidebar and upload any custom .png skin with one click. Built on a hardware-accelerated dark WPF UI.

  • Master animation toggle and Low-Performance Mode in Settings & Tools for lighter hardware.
  • Instant skin switching and live preview cube without launching the game first.
06 // SYSTEM DIAGNOSTICS

Bundled BUGrock_Check Repair Utility

Diagnose package installation or Windows Store service issues automatically with the bundled BUGrock_Check helper tool.

  • Inspects core Windows deployment & gaming services: AppXSvc, ClipSvc, GamingServices, and wuauserv.
  • Performs 1-click startup repair if any required system service is stopped or disabled.

System Requirements & Quick Setup

Honest prerequisites and a quick checklist so packages install cleanly on the first run.

01 // OPERATING SYSTEM

Windows 10 / 11 (x64)

Windows 10 (Build 17763 or newer) or Windows 11 on 64-bit x64 architecture.

02 // UWP PACKAGES

Developer Mode ON

Required by Windows to sideload .appx packages cleanly.

Settings > System > For developers
03 // EXTRACTION PATH

Short Folder Path

Extract the ZIP to a short path to avoid Windows MAX_PATH errors.
