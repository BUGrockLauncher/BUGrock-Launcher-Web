Everything You Need To Master Bedrock

Unlike the standard Microsoft Store launcher, BUGrock Launcher provides low-level control, version decoupling, and custom package staging.

Side-by-Side Installations

Install as many Release, Preview, and Beta versions as your drive can hold. Play old updates with friends or test experimental 1.21+ features without overwriting existing files.

GDK (.msixvc) & UWP (.appx) Support

Full staging, extraction, and manifest patching for modern GDK versions. Automatic background decryption key verification so you never get stuck on encryption errors.

Interactive 3D Skin Viewer

Built-in 3D viewport right in the launcher sidebar! The character head dynamically tracks your cursor, with live upload support for custom PNG skins and Steve/Alex presets.

Smart World Migration

Never lose a Minecraft world again. Automatically scans and synchronizes world folders across legacy UWP LocalState and modern GDK Users directories with conflict resolution.

Instant Switcher & Live Meter

Switch packages directly from the main Play tab. Real-time download speed monitoring in MB/s with live progress percentage and instantaneous cancelation support.

100% Transparent & Secure

No third-party trackers, no adware, and no hidden telemetry. Written in clean C# (.NET 8.0) and MSVC C++ shims, compiled transparently under the GNU GPL-3.0 license.

Quick Start

Get Up And Running In 3 Steps

No complicated installers or registry hacks. Fully portable and ready to play.

01

Download & Extract

Download the latest BUGrock_Launcher_v1.0.0_win-x64.zip release and extract it to a short path like:

C:\BUGrock
02

Enable Dev Mode

Ensure Windows Developer Mode is ON so sideloaded UWP & GDK packages can be registered on your machine.

ms-settings:developers
03

Launch & Play

Run BUGrock_Launcher.exe, select any version in the Installations tab or import your local package, and click PLAY!
